| **`Id`** | `Guid` | `UNIQUEIDENTIFIER` | **Khóa chính (Primary Key).** Sinh tự động (Auto-generated). Sử dụng `Guid` giúp dễ dàng đồng bộ dữ liệu giữa các hệ thống phân tán, hoặc bạn có thể dùng `long` (BIGINT tự tăng) nếu muốn tối giản. |

| **`Title`** | `string?` | `NVARCHAR(1500)` | Nội dung mô tả (Caption) và bộ hashtag của video. Cần hỗ trợ Unicode (NVARCHAR) để lưu tiếng Việt và emoji. |
| **`ThumbnailUrl`** | `string` | `VARCHAR(1000)` | URL ảnh bìa tĩnh do API trả về. Dùng để load nhanh trên danh sách của Mobile App mà không cần tải video. |

| **`ViewCount`** | `int` | `INT` | (Tùy chọn) Lưu số lượt xem tại thời điểm hệ thống cào dữ liệu để hiển thị tương tác trên UI. |

Để đảm bảo hiệu năng truy vấn cho Mobile App (đặc biệt khi dữ liệu lớn dần lên và cần phân trang), bạn nên cấu hình Fluent API trong file `DbContext` của .NET như sau:

```csharp
protected override void OnModelCreating(ModelBuilder modelBuilder)
{
    modelBuilder.Entity<TiktokFeed>(entity =>
    {
        entity.HasKey(e => e.Id);
        
        // Đảm bảo không lưu trùng lặp video
        entity.HasIndex(e => e.VideoId).IsUnique();
        
        // Đánh index cho cột PublishedAt để tăng tốc độ phân trang (Order By Desc)
        entity.HasIndex(e => e.PublishedAt);
    });
}
```
